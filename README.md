# Saúde Pet

Primeiro petshop ai-first do Brasil em arquivo único (`index.html`). Clínica real de BH: equipe nominal, guia de vacinas interativo, depoimento, agendamento e assistente.

Produção: https://petshop-saudepet-production.up.railway.app

Deploy: Railway, projeto `petshop-saudepet`, serviço ligado ao repo com Dockerfile nginx na porta 8080.

```powershell
python -m http.server 8000
```
